# Measurable

## Overview
Measurable is an Android app designed to help users track their skill development over time. By recording tested performance on specific skills, users can see their progress and stay motivated to continue improving.

## Features
- Track and record skill performance over time.
- Store test results using Android's built-in SQLite database.
- View progress through.
- User-friendly interface for quick and easy updates.

## How It Works
1. **Record a Skill Test** – Users input their performance on a particular skill.
2. **Save Progress** – Data is stored locally using SQLite.
3. **View Progress** – Users can see improvements over time through the app’s graphical interface.
4. **Stay Motivated** – Regular tracking encourages users to refine and enhance their skills.

## Technical Details
- **Platform:** Android
- **Local Storage:** SQLite
